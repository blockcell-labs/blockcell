# Genesis 开发者文档

Genesis 是 Blockcell 的仓库级自改进实验控制器。它从锁定的源码版本起步，让当前 Blockcell Agent 诊断失败并提出、实现补丁，再由独立的 Python Supervisor 编译、隔离评测和记录结果。符合继承条件的候选可在后续轮次承担同样的工作，形成递归自改进闭环。晋级版本和符合条件的归档版本均可参与父代选择。

这套文档面向想运行实验、理解实现、添加评测或参与维护的开发者，依据 v0.1.4 当前源码编写。Python 控制器只依赖标准库；运行真实实验还需要 Rust 工具链、Blockcell 源码、模型服务及外部评测资源。

## 阅读约定

- **实现事实**描述当前源码行为；配置默认值不代表适用于所有模型或机器。
- **实验结果**必须同时说明源码 SHA、模型、题库版本、配置和运行环境，不能只引用一个通过数。
- **改进方向**表示仍需工程验证的工作，不属于当前版本承诺。
- 命令默认在 Blockcell 仓库根目录执行，示例使用 `python3`。运行产物保存在配置指定的实验工作区。

本机已完成的运行验收环境为 macOS 15.7.3 / Intel x86_64。Apple Silicon 尚未实机验收；Linux bubblewrap 后端需要独立验收。Genesis 是实验型 Supervisor 的源码发布，当前不能据此宣称完整 Agent 已获得安全生产认证。
