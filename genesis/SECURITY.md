# 运行与依赖边界

Genesis 使用 Python 3.10+ 标准库，不打包第三方 Python 依赖。发布包不应包含密钥、模型响应、工作区数据库或本机编译缓存。
运行前请在 `doctor` 中确认原生隔离可用，真实候选始终使用 `require_bwrap=true`。

Supervisor 是可信控制器；锁定源码、外部评测器及配置属于可信输入。候选源码、构建脚本和生成的 Python 代码属于不可信执行，使用本机沙箱隔离。macOS Seatbelt 不提供虚拟机或 Linux PID namespace 级隔离，建议使用独立实验账户和机器。

被选中的 Blockcell Rust 依赖属于单独的供应链。Genesis 的审计门禁比较 Parent 和候选的新增漏洞；它不会把 Parent 的现有漏洞自动消除，也不能把“没有新增漏洞”解释为“没有漏洞”。应在采用 Parent 前独立评估其审计报告。不要将已知有风险的 Parent 暴露于不可信网络或文件。

默认源码锁定 SHA 用于复现，不是零漏洞认证。本次锁定源码的离线审计发现 42 个唯一 advisory、62 个包版本记录，包括 TLS、归档、文档解析、SMTP 和 SQLite 依赖。该情况保留在发布验证报告中，未通过忽略规则消除。发布的 Python Supervisor 不携带这些库或二进制；运行时自行构建的 Agent 会使用相应依赖。

费用为按配置单价和模型 usage 计算的估值。保守预留必须足以覆盖未知请求；没有可靠依据时应保持运行阻断。不得将预留额解释为供应商已结算账单。
