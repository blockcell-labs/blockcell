# v0.1.4 发布完善

- macOS Seatbelt 原生隔离，候选仅可访问工作目录、只读工具链及计量代理；验证器离线隔离，EAB 网关与题库分离。
- Parent 资格持久化，危险 ARCHIVE 不参与探索；晋级保存 detached 提交，不创建分支。
- 工作区跨进程锁、构建恢复、预算恢复及幂等状态记录。
- 通用 OpenAI 兼容配置，完整 JSON 上游转 SSE，可保留文本、推理和工具调用；异常请求不自动重放。
- 非法或缺失 usage 持久化阻断；显式未知费用预留计入预算并保留历史记录。
- coding/EAB 逐题恢复和运行环境绑定的 L0 缓存。
- L0 测试新建的本地 target 运行目录归档，避免测试日志被误计入候选补丁；保留原有目录和缓存链接。
- 上游 5xx/畸形响应按基础设施故障暂停，不误判候选能力；EAB hook 与本地流中断服务采用精确权限。
- 子进程信号清理、原生传输独立会话、自检软链接拒绝及前置环境检查。

本机验证：macOS 15.7.3 / Intel x86_64；Apple Silicon 未实机验收。Linux bubblewrap 路径为实验性，未由本机真实验收。
这是 Supervisor 的源代码发布，不包含模型、EAB60 外部套件或已通过安全审计的 Blockcell 二进制。
实际模型能力和进化效果以真实评测报告为准；正常拒绝候选不构成 Supervisor 失败。
